# Personal skills

This repository contains the agent workflows I use for personal software projects. Each workflow lives in its own directory under `skills/` and keeps its instructions and client metadata together.

## Available skills

- [`experiment`](skills/experiment/SKILL.md) bootstraps a Personal Experiment and builds its first working outcome with disposable code and minimal process.

The repository stays intentionally small. Workflow-specific guidance belongs in the skill that owns it; root documentation only explains the collection and how to maintain it.
